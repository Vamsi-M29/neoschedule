# NeoSchedule
NeoSchedule is a modern responsive calendar dashboard UI concept built using HTML, Tailwind CSS, and JavaScript.
## Features
- Responsive calendar dashboard
- Interactive calendar grid
- Sidebar navigation
- Event cards
- Animated UI interactions
- Modal popup interface
- Modern productivity-inspired design
- Smooth hover effects and transitions
## Tech Stack
- HTML
- Tailwind CSS
- JavaScript
## Project Type
Frontend UI Concept Project
## Purpose
This project was created to practice frontend development, responsive layouts, dashboard design, and modern user interface concepts.
